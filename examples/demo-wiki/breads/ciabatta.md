# Ciabatta

**Summary**: A very wet Italian loaf with a wide, irregular crumb.

Created in 1982 as a response to the baguette's popularity, it uses a high hydration that rules out [[kneading]] by hand.

## Structure

It is built by [[stretch-and-fold]] and a pre-ferment; see [[fermentation]].
